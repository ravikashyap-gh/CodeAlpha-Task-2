# Unemployment Analysis with Python

## Project Description

This project analyzes unemployment data in India to identify trends and patterns in unemployment rates across different states and regions.

### Key Areas Covered

- State-wise Unemployment Analysis
- Rural vs Urban Comparison
- COVID-19 Impact Analysis
- Seasonal Trend Analysis
- Correlation Analysis

## Technologies Used

- Python
- Pandas
- Matplotlib
- Seaborn
- NumPy

## Features

- Data Cleaning and Preprocessing
- Exploratory Data Analysis (EDA)
- Data Visualization
- Trend Analysis
- Statistical Insights

## Analysis Performed

- Average Unemployment Rate Calculation
- State-wise Comparison
- Monthly Trend Analysis
- COVID-19 Impact Study
- Top 10 States with Highest Unemployment
- Correlation Heatmap

## Visualizations

- State-wise Average Unemployment Rate
- Unemployment Trend Over Time
- Rural vs Urban Comparison
- COVID-19 Impact Graph
- Seasonal Trend Analysis
- Correlation Heatmap

## Key Findings

- COVID-19 significantly increased unemployment rates.
- Unemployment varies across different states.
- Rural and urban areas show different employment patterns.
- Seasonal fluctuations can be observed in the data.

## How to Run

### Install Dependencies

```bash
pip install pandas matplotlib seaborn numpy
```

### Run the Project

```bash
python unemployment_analysis.py
```
