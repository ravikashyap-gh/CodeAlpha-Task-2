Unemployment Analysis with Python

Project Description

This project analyzes unemployment trends in India using Python. The analysis includes data cleaning, exploratory data analysis (EDA), visualization of unemployment rates, COVID-19 impact analysis, rural vs urban comparison, and seasonal trend identification.

Technologies Used

Python
Pandas
Matplotlib
Seaborn
NumPy

Exploratory Data Analysis (EDA)
State-wise Unemployment Analysis

Key Findings

COVID-19 significantly increased unemployment rates during lockdown periods.
Unemployment rates vary across different states in India.
Rural and urban areas show different unemployment patterns.
Seasonal fluctuations are visible in unemployment trends.

How to Run

Install dependencies

pip install pandas matplotlib seaborn numpy

Run

python unemployment_analysis.py
